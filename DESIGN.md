# DESIGN

## Color Strategy: Restrained
- Base: `oklch(15% 0.01 250)` (Deep Slate Blue)
- Surface: `oklch(20% 0.015 250)`
- Text: `oklch(90% 0.01 250)`
- Accent: `oklch(70% 0.15 200)` (Electric Cyan)
- Success: `oklch(75% 0.15 150)` (Mint)

## Typography
- Main: Inter (System UI fallback)
- Mono: JetBrains Mono / SF Mono (for technical details)
- Scale: 1.333 (Perfect Fourth)

## Layout Principles
- Strict 12-column grid.
- High contrast spacing (large gaps between sections, tight gaps between related data).
- Use of mono-type for "status" indicators to lean into the NOC aesthetic.

## Motion
- Direct, fast transitions. 200ms ease-out-expo.
